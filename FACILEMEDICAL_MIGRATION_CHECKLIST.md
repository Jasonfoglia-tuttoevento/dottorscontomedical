# Checklist migrazione esterna FACILEMEDICAL.IT

Le attività seguenti richiedono accesso a servizi esterni e non sono completate da questo rebranding del repository.

- [ ] Registrare e configurare `facilemedical.it`.
- [ ] Configurare i record DNS del dominio.
- [ ] Configurare Vercel o la piattaforma di hosting scelta.
- [ ] Impostare le variabili ambiente di produzione senza copiare segreti nel repository.
- [ ] Aggiornare Supabase Auth Site URL a `https://facilemedical.it`.
- [ ] Aggiornare le Supabase Auth redirect URLs.
- [ ] Aggiornare allowed origins e CORS applicabili.
- [ ] Aggiornare i template email Supabase con il brand Facile Medical.
- [ ] Verificare e configurare il dominio mittente in Resend.
- [ ] Configurare SPF, DKIM e DMARC.
- [ ] Attivare `info@facilemedical.it` e `support@facilemedical.it`.
- [ ] Configurare Analytics con consenso appropriato.
- [ ] Configurare Google Search Console.
- [ ] Implementare e configurare il cookie banner.
- [ ] Pubblicare e far validare la privacy policy.
- [ ] Pubblicare e far validare termini e condizioni.
- [ ] Pianificare eventuali redirect 301 dal vecchio dominio.
- [ ] Rinominare il repository GitHub, se approvato.
- [ ] Aggiornare il remote Git locale solo dopo la rinomina del repository.
- [ ] Verificare disponibilità del marchio e denominazione legale con consulenti qualificati.
